# Filter Bloom — Support & Issue Tracker

This is the public bug tracker and feature-request board for **Filter Bloom**, a graduated multi-step filter sequencer plug-in (AU / VST3) by Cryptic Arts Laboratory.

Filter Bloom layers up to 8 parallel filter bands, each driven by drawable per-step envelopes (magnitude, amplitude, frequency, Q, resonance, detune) locked to your DAW's beat clock.

> Filter Bloom's source code is not public — this repository exists so you can report bugs and request features.

## Downloads

Get the latest installers (macOS `.pkg` — signed & notarized; Windows `.exe`) at
**[phonomenon.crypticartslab.com/downloads](https://phonomenon.crypticartslab.com/downloads)**

The plug-in also checks for updates automatically and from its Settings popout.

## Reporting a bug

[Open a bug report](../../issues/new?template=bug_report.yml) — please include your plug-in version, OS, DAW, and steps to reproduce. The version number is shown in the plug-in's Settings popout.

## Requesting a feature

[Open a feature request](../../issues/new?template=feature_request.yml) — tell us what you're trying to do musically, not just the control you want; it helps us design the right thing.
